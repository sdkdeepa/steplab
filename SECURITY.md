# Security

## Reporting a problem

Please **don't** open a public issue for a security problem. Report it privately instead:

1. Go to the repo's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe what you found, how to reproduce it, and what could happen.

You'll get a reply as soon as possible. Please give a reasonable amount of time to fix the problem before you share it publicly.

## What's in scope

- The StepLab website and the labs it renders, including markdown that could run unwanted code
- Downloaded single-file HTML labs
- The VS Code / Antigravity IDE extension
- The Docker image `ghcr.io/sdkdeepa/steplab`

## Supported versions

Only the latest release gets security fixes. Update the extension and pull the newest Docker image to stay current.
